# Existing manuscript summaries

`paper_summary.csv` records exact unordered clean-reference set fidelity from
the revised Pattern Analysis and Applications manuscript, including the
completed ViT-reference condition. Values are percentages; change is attacked
minus clean, rounded from the underlying unrounded estimates.

Clean and attacked entries here refer to the comparable attacked holdouts,
not the separate large clean-utility runs. ViT is the online reference; the
defended output and input gradients come from ResNet-50.

These are existing summaries. No new dataset-backed experiment was run for
this code refactor. The CPU demonstrations are not included in this table.
The status column identifies a manuscript snapshot, not a fresh release-level
scientific audit.

Source: the manuscript's baseline/component tables, cross-checked against the
existing analysis. The original raw draws, images, weights and candidates are
not redistributed in this archive.
