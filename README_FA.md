# راهنمای فارسی کد پژوهش Top-k

این نسخه، هستهٔ همان کدهای پژوهش شما را به فایل‌های کوچک‌تر و قابل استفادهٔ
مجدد تقسیم می‌کند. فرمول دفاع، ترتیب گام‌ها، نویز، کاندیداهای حمله و بودجهٔ
کوئری با کد اصلی مقایسه شده‌اند. فایل‌های ثبت‌شدهٔ آزمایش‌ها نیز در
`experiments/frozen/` نگه داشته شده‌اند.

## شروع سریع

از پوشهٔ اصلی مخزن، پس از نصب PyTorch مناسب سیستم:

```bash
python -m pip install -e ".[test,dev]"
python -m topk_fidelity demo --attack SquareAdaptive
python -m topk_fidelity demo --attack SquareRacing
python -m topk_fidelity show-config --config configs/cifar10.json
pytest -q
```

دستور `demo` الگوریتم‌ها را روی مدل و تصویر کوچکِ ساختگی اجرا می‌کند؛
عددهای آن نتیجهٔ مقاله محسوب نمی‌شوند.

## کد را از کجا بخوانم؟

| فایل یا پوشه | کاربرد |
|---|---|
| `src/topk_fidelity/defense.py` | دفاع: مرجع آنلاین، تقویت حاشیه، نویز و خروجی همهٔ لاجیت‌ها |
| `src/topk_fidelity/config.py` و `configs/` | تنظیمات صریح هر دیتاست و نسخه‌های Robust / Full / Noise-only |
| `src/topk_fidelity/attacks/` | هدف حمله، پیشنهاد Square، آرشیو کاندیدا و دو حلقهٔ حمله |
| `src/topk_fidelity/query.py` | شمارش واقعی پاسخ‌ها برای هر تصویر |
| `src/topk_fidelity/metrics.py` و `evaluation.py` | متریک‌ها و ارزیابی مستقل هر پاسخ تصادفی |
| `src/topk_fidelity/models/` | معماری‌های اصلی CIFAR و خواندن وزن‌های قبلی |
| `src/topk_fidelity/training/losses.py` | همان زیان رتبه‌بندی Top-2 و distillation آموزش |
| `docs/MIGRATION.md` | نگاشت تابع‌های قدیمی به فایل‌های مرتب‌شده |
| `docs/VALIDATION.md` | نتیجه و محدودهٔ بررسی‌ها |

برای CIFAR-10، مدل دفاع از `robust_branch` نرمال‌شدهٔ چک‌پوینت دوشاخه
استفاده می‌کند. در آزمایش ViT، مدل ViT مرجع آنلاین است و ResNet-50 گرادیان
و لاجیت خروجی را تولید می‌کند.

## اجرای داده‌ها و وزن‌های خودتان

فایل ورودی `.pt` باید شامل `images` با ابعاد `[N,3,32,32]` و مقادیر
پیکسلی بین صفر و یک، `labels` با نوع int64، و `image_ids` یکتا باشد.
دستور نمونه و قالب خروجی در [README.md](README.md) آمده است.

اجرای جدید از روی تنسور دلخواه، خودبه‌خود بازتولید رسمی مقاله نیست؛ برای
اسپلیت‌ها، هش‌ها و مراحل رسمی از
[docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md) استفاده کنید.
برای این بازآرایی، آموزش GPU و آزمایش کامل دیتاست‌ها دوباره اجرا نشده‌اند.

مرجعِ تمیز برای هدف حمله و ارزیابی ثابت است؛ دفاع مرجع آنلاین را برای هر
درخواست دوباره محاسبه می‌کند. خروجی همچنان شامل **همهٔ لاجیت‌ها** است.
حفظ مجموعهٔ Top-k به معنی حفظ مقدار سایر لاجیت‌ها یا کالیبراسیون نیست.

## قرار دادن در مخزن

ZIP را باز کنید و محتویات پوشهٔ `clean-reference-topk-fidelity` را در ریشهٔ
مخزن قرار دهید. وزن‌ها، دیتاست‌ها و خروجی‌های اجرا را اضافه نکنید؛ مسیرهای
آن‌ها از قبل در `.gitignore` مشخص شده‌اند. فایل‌های تنظیمات مخزن و گردش کار
CI هم در بسته وجود دارند.

جدول نتایج و توضیح نقش ViT با نسخهٔ بازنگری‌شدهٔ مقاله هماهنگ شده‌اند.
مشخصات نویسندگان و لینک واقعی مخزن را پیش از انتشار در
`CITATION.cff.template` تکمیل کنید. این بسته در GitHub منتشر نشده است.
