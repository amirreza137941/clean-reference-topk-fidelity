# گذاشتن این بسته در GitHub با رابط وب

بستهٔ ZIP را روی کامپیوتر خود باز کنید. فایل‌های داخل
`clean-reference-topk-fidelity` باید در ریشهٔ مخزن قرار بگیرند؛ بارگذاری خود
ZIP، کدها را در GitHub باز نمی‌کند.

اگر مخزن را تازه می‌سازید، نام `clean-reference-topk-fidelity` مناسب است.
README، LICENSE و gitignore داخل بسته هستند؛ هنگام ساخت مخزن، نسخهٔ دیگری
از آن‌ها نسازید. اگر مخزن از قبل وجود دارد، یک شاخه برای بازآرایی ایجاد کنید.

در صفحهٔ مخزن، **Add file → Upload files** را انتخاب کنید. فایل یا پوشه‌ها
را به صفحه بکشید، پیام commit بنویسید و تغییر را در شاخهٔ مربوط ثبت کنید.
چون تعداد فایل‌های این بسته بیشتر از ۱۰۰ است، بارگذاری را در چند مرحله
انجام دهید؛ GitHub در هر بارگذاری وب تا ۱۰۰ فایل و برای هر فایل تا ۲۵ MiB
می‌پذیرد.

فایل‌های اصلی، `src/`، `configs/`، `tests/` و مستندات را ابتدا اضافه
کنید. `experiments/frozen/` نیز باید در چند دسته بارگذاری شود و نام و مسیر
فایل‌ها حفظ شود. فایل‌های مخزن مانند `.gitignore`، `.gitattributes` و
`.github/workflows/ci.yml` را هم اضافه کنید.

وزن‌ها، دیتاست‌ها و خروجی‌های اجرای شخصی جزو این بسته نیستند. در پایان
بررسی کنید README در صفحهٔ اصلی دیده شود، ساختار پوشه‌ها حفظ شده باشد و CI
اجرا شود. انتشار یا push توسط این بازآرایی انجام نشده است.

راهنمای قدیمی SaTML و وضعیت «ViT در حال اجرا» دیگر مبنای این نسخه نیست.
نام نویسندگان و لینک واقعی را در الگوی citation تکمیل کنید؛ سیاست ارسال
مقاله را از راهنمای هدف فعلی بررسی کنید.
